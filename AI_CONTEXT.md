# AI_CONTEXT — SewMaster

> **Этот файл — для ИИ-ассистента.** Прочитай его целиком, прежде чем
> менять код проекта. После завершения работы ОБНОВИ этот файл
> (раздел «Что сделано» и «Дальше»).

## 1. Исходное задание пользователя (ТЗ)

Написать программу для шитья одежды и собрать исполняемый файл для
**Windows 7–11**. Главное в проекте — **итоговый .exe**.

Требования (все реализованы в v1.0.0, если не указано иное):

1. Скачивать выкройки моделей одежды из доступных источников интернета
   по желанию пользователя → реализовано как онлайн-каталог из этого же
   GitHub-репозитория (catalog/index.json, пресеты моделей).
2. Сразу уметь строить выкройки **трусов и маек** → 4 модели: слипы,
   боксёры, майка, футболка.
3. Предложить пользователю модели, спросить нужные размеры (мерки),
   начертить выкройки **с напусками (припусками) для швов**.
4. Распечатать на обычном принтере: **A4 с метками для склеивания листов**
   (круглые метки совмещения, линии обрезки, контрольный квадрат 10×10 см,
   масштаб 1:1) — если выкройка не умещается на одном листе.
5. Сделать **инструкцию по шитью для человека, который шьёт впервые**
   (пошагово, со словарём терминов).
6. Учитывать **швейную машину пользователя** (какие швы доступны):
   при отсутствии оверлока предлагать другие способы (зигзаг,
   бельевой/французский шов, двойная игла, ручная обработка).
7. Уметь **сохранять разработанные выкройки** (проекты .sewproj).
8. В репозитории должен быть файл, по которому ИИ быстро поймёт задание
   и продолжит разработку — вот этот файл.

Решения, принятые пользователем (опрос 2026-11-23): интерфейс только
русский; 4 модели; печать через PDF (A4); название SewMaster; репозиторий
публичный; лицензия MIT; единицы — см; инструкция в PDF + окно программы.

## 3. Архитектура (кратко)

```
app.py                     точка входа (DPI-awareness, обработчик ошибок)
core/                      ЯДРО — без tkinter, тестируется головless
  geom.py                  Contour: start + segs [('L',p)|('C',c1,c2,p)]
                           points()/seg_groups() — дискретизация;
                           offset_multi(припуски по сегментам) — линия кроя
                           с miter-join; offset(d) — равномерный.
  piece.py                 PatternPiece (contour=линия шва, cut_poly=крой,
                           allowance_edges, notches, folds, grain, labels),
                           SeamInfo, DraftResult (pieces, checks, seams,
                           fabric, elastic, notes)
  models.py                ModelDef/Field/ParamField — реестр моделей,
                           таблицы типовых размеров WOMEN_SIZES/MEN_SIZES,
                           size_defaults(audience, size)
  drafts/*.py              build(meas, params) -> DraftResult:
                           briefs (слипы), boxers, tank (майка), tee (футболка)
  sewing.py                MACHINES (4 профиля), join_steps/elastic_steps/
                           hem_steps/binding_steps/neck_rib_steps — тексты
                           способов обработки под машину
  instructions.py          build_instructions() -> секции с блоками
                           ('h'|'p'|'step'|'tip'|'warn'), instructions_to_text()
  pdfout.py                PdfDraw (reportlab, мм!, y вниз), export_pdf():
                           титул → листы деталей (cell 190x277мм, кроп-метки,
                           круглые метки совмещения, сетка 10 см) → инструкция
  storage.py               Project (.sewproj JSON), settings.json, recent
  catalog.py               fetch_catalog (GitHub raw), catalog_model_to_def,
                           локальное хранение в %APPDATA%/SewMaster/catalog
  paths.py                 project_root() (работает и в PyInstaller: _MEIPASS),
                           app_data_dir()
gui/                       tkinter: windows.py (главное+каталог+инструкция+
                           справка), wizard.py (мастер 5 шагов),
                           preview.py (канвас, зум/панорама), theme.py
assets/fonts/              DejaVuSans + Bold (кириллица в PDF)
assets/icons/              icon.ico / icon.png (генератор scripts/make_icon.py)
catalog/index.json         ОНЛАЙН-КАТАЛОГ (этот же репозиторий, ветка main)
```

Поток данных: `ModelDef.build(meas, params) -> DraftResult` → GUI рисует
DraftResult → `export_pdf()` пишет PDF; `build_instructions()` использует
DraftResult.seams + профиль машины.

## 4. Критичные соглашения и грабли

- **Единицы**: core — сантиметры, ось Y ВНИЗ (экранная). pdfout переводит
  в мм (×10). НЕ менять направление оси — вся разметка PDF/превью на этом
  построена.
- **reportlab в пунктах**: PdfDraw применяет `c.scale(72/25.4)` и
  **повторяет его после каждого showPage()** (showPage сбрасывает
  состояние!). Не удалять этот повтор — иначе контент уедет в левый нижний
  угол страницы.
- **Сегменты контура**: `allowance_edges` должен иметь длину
  `len(contour.segs)`; порядок сегментов см. в докстрингах drafts/*.py.
  Сгиб — припуск 0.
- **Стороны совмещаемых швов**: у майки/футболки боковые швы переда и зада
  совпадают, т.к. общая точка U. Есть assert — не ломать.
- **Python 3.8**: НЕ использовать синтаксис 3.9+ (dict |, list[int] без
  __future__). Аннотации — через typing.
- **PyInstaller**: `--add-data "assets;assets"` (разделитель `;` на Windows).
  Путь к ресурсам — только через core.paths.asset_path().
- **Win7**: собирать ТОЛЬКО на Python 3.8.x (3.8.10) и PyInstaller 5.13.2.
  reportlab==4.2.5 (4.4+ требует py3.9!). Новые версии Python/PyInstaller
  сломают Win7.
- **Каталог**: URL зашит в core/catalog.py (raw.githubusercontent.com).
  После переименования репозитория поправить URL.
- **GUI-шрифт**: gui/theme.py: ui_family() — Segoe UI на Windows, фолбэки
  на Linux. В песочнице/CI Linux Xvfb кириллица в tkinter НЕ рендерится
  (нет Xft) — это нормально, на Windows всё ок. Проверять вёрстку по
  структуре, а не по тексту.
- **Тесты визуальные**: tests/render_previews.py + pdftoppm + просмотр
  страниц. При правке геометрии ОБЯЗАТЕЛЬНО смотреть превью всех 4 моделей.
- **Урок v1.0.0**: NameError внутри обработчика кнопки ловится глобальным
  report_callback_exception (app.py) и выглядит для пользователя как
  «непредвиденная ошибка». Такие баги ловятся ДО релиза шагом pyflakes
  в CI — не удалять его и не добавлять код без запуска `python -m
  pyflakes app.py gui core tests` (искать «undefined name»).

## 5. Математика построений (допущения)

Методики упрощённые, для домашнего пошива (это осознанное решение):
- Слипы: перед/зад на сгибе, ширины Об/4+0.25/1.25+ease/2, ластовица 3.5/5.5,
  вырез ноги — кубическая Безье, средний шов короткий.
- Боксёры: панели равной ширины, штанина расширяется к низу
  (leg_w=бедро/2+1.5), шаговая точка на Вс-9.5/-8.
- Майка: U=(w-1.2, arm_d) общий для переда/зада; arm_d=Ог/10+9.
- Футболка: drop-shoulder, arm_d=Ог/10+12(+2 oversize), скос плеча 4,
  рукав — трапеция с лёгкой стрелкой оката.
- Все допущения написаны в комментариях файлов drafts/. Точность посадки
  не гарантируется — в инструкциях есть совет шить пробник из простыни.

## 6. Как добавить новую модель (чек-лист)

1. `core/drafts/<model>.py`: функция `build(m, p) -> DraftResult`
   (скопировать структуру tank.py — самый простой).
2. Зарегистрировать в `core/drafts/__init__.py` (BUILDERS).
3. Добавить ModelDef в `core/models.py` (мерки с подсказками, параметры).
4. При желании — добавить пресет в `catalog/index.json`.
5. Прогнать `python tests/smoke.py` и `tests/render_previews.py`,
   посмотреть PNG всех деталей.
6. Обновить этот файл (раздел 2) и README.

## 8. Сборка и выпуск релиза

- CI: `.github/workflows/build.yml` — на каждый push в main собирает exe
  (артефакт «SewMaster-windows»), на тег `v*` создаёт Release с exe.
- Выпустить версию: `git tag v1.1.0 && git push origin v1.1.0`.
- Локальная сборка на Windows: см. README (pyinstaller-команда).
- Перед релизом: `python tests/smoke.py` зелёный; проверить превью всех
  моделей; проверить PDF (титул/листы/инструкция) глазами.
